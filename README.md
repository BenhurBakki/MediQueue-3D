# MediQueue-3D: Real-Time Healthcare Management System

MediQueue-3D is a cutting-edge, real-time hospital management and appointment system designed to optimize patient flow and reduce wait times. By leveraging modern web technologies, it provides a seamless experience for both doctors and patients through live queue tracking and automated scheduling.

## 🚀 Key Features

- **Real-Time Queue Tracking**: Patients can monitor their position in the queue live from any device.
* **3D-Inspired Interface**: A modern, responsive design optimized for healthcare environments.
* **Doctor Dashboard**: Specialized views for healthcare professionals to manage appointments and patient flow.
* **Secure Authentication**: Integrated login and signup systems for patient data privacy.
* **Instant Notifications**: Automated alerts for appointment confirmations and status updates.
* **Smart Booking**: An intuitive interface for selecting doctors and preferred time slots.

## 🛠️ Technology Stack

* **Backend**: Python (Flask)
* **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+)
* **State Management**: Real-time updates for queue synchronization.

## 🚥 Getting Started

### Prerequisites
- Python 3.8+
- pip (Python package manager)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/BenhurBakki/MediQueue-3D.git
   ```
2. Navigate to the project directory:
   ```bash
   cd MediQueue-3D
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the server:
   ```bash
   python app.py
   ```
